What this page is

Elevate directs your browser here after you grant (or decline) admin consent for the shared Elevate app registration in your Microsoft tenant. Microsoft appends the result to this page’s address as query parameters, which the script on this page reads and displays — nothing is uploaded, logged or stored, on this site or anywhere else. You can close this tab and return to Elevate.
