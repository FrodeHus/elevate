# Elevate for Windows

Planned Windows 11 counterpart of the macOS app: a system-tray flyout built with WinUI 3 on .NET 10, installed from an MSI and published to winget as `Reothor.Elevate`.

Status: designed, not yet implemented. See the [design spec](../docs/superpowers/specs/2026-09-05-elevate-windows-design.md) and the implementation plan in `docs/superpowers/plans/`.
